# Konfederacja Generalna 1648 — Sądy Kapturowe

## Streszczenie

Część Konfederacji Generalnej regulująca sądy kapturowe i approbatę laudów wojewódzkich.

### Kluczowe postanowienia

| Postanowienie | Opis |
|---|---|
| Sądy kapturowe | Nadzwyczajna przysięga *super iuste iudicando* dla sędziów |
| Zakres spraw | Tylko sprawy od dnia śmierci króla do dnia koronacji nowego pana |
| Actiones criminis | Sprawcy przemocy i personalnych injurii |
| Księstwo Oświęcimskie i Zatorskie | Tymczasowo dopuszczone do sądów generalnych kapturowych krakowskich |
| Lauda Koronne | Approbowane vigore Conventus praesentis |
| Lauda WXL | Approbowane, ale *pro hac vice* — nie może derogować iuri communi |

### Immunitet

- Od popisu wolni senatorowie i posłowie jadący na konwokację
- Starostom nie szkodzi, że nie wykonują dekretów trybunalskich przed śmiercią króla — muszą wykonać po koronacji, intra sex septimanas
