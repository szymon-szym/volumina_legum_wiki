# Instruktarz celny 1643 — Od których towarów płacić podatki

## Streszczenie

Szczegółowy wykaz towarów podlegających cłu (*ab inductis mercibus*), miejsce czwartego grosza — po kopie od sta złotych.

### Kategorie towarów

| Kategoria | Przykłady |
|---|---|
| Klejnoty | Perły, koralle, drogie kamienie, łańcuchy złote, pasy srebrne |
| Towary jedwabne | Złotogłowy, tabiny, aksamity, atlasy, adamaszki, kitajki |
| Sukna | Weneckie, hiszpańskie, francuskie, angielskie, holenderskie, śląskie |
| Płótna | Holenderskie, koleńskie, flamskie, szwabskie, głogowskie, wrocławskie |
| Korzenie | Szafrany, pieprz, cynamon, gwoździki, imbier, cukier |
| Futra | Sobole, rysie, lisy, kuny, bobry, lamparty, wydry |
| Likwory | Wina, piwa zamorskie, miody, śledzie, ryby słone |
| Skóry | Jelenie, łosiowe, wołowe, bawole, sarnie |
| Bydła | Woły, czabany, barany, konie z Wołoch, Multan |
| Towary tureckie | Kobierce, kilimy, szable, futra egipskie |

### Cło generalne

Od wszystkich towarów nie wyspecyfikowanych — po 2 złote od sta złotych.
