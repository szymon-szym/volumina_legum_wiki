# Pacta Conventa 1648 — Artykuły Jana Kazimierza

## Streszczenie

Artykuły, na które przysiągł [[Jan II Kazimierz Waza|Jan Kazimierz]] po elekcji w 1648 r.

### Kluczowe zobowiązania

| Zobowiązanie | Opis |
|---|---|
| Pokój religijny | Pokój między dysydentami w religii chrześcijańskiej; uspokojenie religii greckiej |
| Aparat wojskowy | Porządna ekonomia bellica — saletry, Rudy, prochy, kule, działa; druga kwarta na apparat |
| Szkoła rycerska | We Lwowie, na ćwiczenie ufortyfikowania i rzeczy puszkarskich |
| Pax et foedera | Ponowienie paktów z sąsiadami; komisja do traktatów ze Szwedami |
| Posłowie do Moskwy | Wysłanie posłów do Cara Moskiewskiego po koronacji |
| Mennica | Przywilej bicia monet należy do RP — król nie będzie bić monety |
| Wojska cudzoziemskie | Zakaz wprowadzania bez zgody RP; zakaz bella offensiva |
| Fortyfikacje | Kamieniec, 4 fortece na Ukrainach, Puck |
| Cudzoziemcy | Zakaz admitowania do rad, urzędów, starostw |
| Dwór | Z narodu polskiego i litewskiego; gwardie z podległych państw |
| Małżeństwo | Ex consilio Senatus na sejmie; cudzoziemskie osoby przy małżonce — ograniczona liczba |
| Ekonomje | Nie przyczyniać bez consensu Ordinum |
| Incompatibilia | Nikomu nie dawać |
| Flota | Rozmowy o sposobieniu classis maritimae |
| Exorbitancje | Naprawa wszystkiego co exorbitowało przeciwko prawu pospolitemu |

### Klauzula nieważności

Jeśli król wykroczy przeciw prawom — obywatele zwolnieni od posłuszeństwa (według konstytucji 1609).
